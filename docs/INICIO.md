# Inicio de Vidres Sosa · Gestión

Aplicación interna con interfaz pública en GitHub Pages y datos privados en Cloudflare Worker, D1 y R2. Sigue [la guía de despliegue y primer acceso](SEGURIDAD-DESPLIEGUE.md) antes de publicar la nueva interfaz.

La migración de los datos locales se realiza únicamente por un administrador, con revisión y copia previa. No hay carga automática de datos locales al abrir la app.
