# Siguientes pasos

Para activar esta entrega:

- Configurar D1 y secretos en la cuenta Cloudflare y desplegar el Worker.
- Completar el primer acceso y retirar el secreto inicial.
- Ejecutar las pruebas de aceptación en navegador y runtime real, comprobar CPU y plan.
- Publicar la interfaz en GitHub Pages y verificar actualización de instalaciones PWA anteriores.
- Importar y comprobar las copias existentes con el administrador, resolviendo referencias entre dispositivos.

Evolución posterior:

- Dominio propio para aislar el origen y permitir cookies HttpOnly en el mismo sitio que la API.
- Recuperación de acceso con proceso operativo, MFA y gestión detallada de dispositivos.
- Sincronización más granular y paginación para volúmenes superiores a los límites de la API de estado.
- Copias automáticas externas, cifrado, retención y pruebas de restauración de D1 y del pepper.
- Agenda semanal por instalador, conflictos de horarios y distribución de trabajo.
- Tratamiento de datos personales: contratos con proveedores, conservación y borrado, derechos y revisión profesional según el uso real.
- Catálogo PDF: sigue registrando nombre/fecha, sin extraer precios ni conservar el documento en Ajustes. Los adjuntos de expediente sí se guardan en D1.
